# Zapret GUI

Удобное окно для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — без чёрных консолей и батников.

**by COFFIOK**

## Зачем это нужно

**zapret** помогает открыть сайты и сервисы, которые плохо работают или не открываются у провайдера: Discord, YouTube, игровые серверы и другие. Он не VPN — трафик идёт напрямую, без чужих серверов, поэтому скорость не падает.

Проблема в том, что сам zapret — это набор батников и текстовых файлов. Чтобы им пользоваться, нужно:
- запускать `.bat`-файлы и держать открытым чёрное окно консоли;
- вручную перебирать два десятка «стратегий», чтобы найти рабочую;
- редактировать текстовые списки, чтобы добавить свой сайт;
- после каждого обновления zapret заново переносить все свои настройки.

**Zapret GUI делает всё это за тебя в одном окне:**
- включаешь и выключаешь zapret **одной кнопкой**;
- выбираешь стратегию из списка, а **встроенный тест** сам покажет, какая работает лучше всего;
- добавляешь сайты в пару кликов и раскладываешь их **по группам**;
- при выходе новой версии zapret **переносишь настройки** одной кнопкой;
- приложение **само обновляется** и не спрашивает права администратора при каждом запуске.

Короче: поставил, нажал кнопку — работает.

## Возможности

- **Пиксельный дизайн** — приложение и установщик в одном стиле; 16 случайных пиксельных анимаций включения, режим экономии без анимаций
- **Включение одной кнопкой** — без окна `winws` на экране
- **Выбор стратегии** из выпадающего списка; при смене zapret перезапускается сам
- **Мои сайты** — свои сайты по группам, добавление и удаление в пару кликов; встроенные списки zapret видны по сервисам
- **Поделиться сайтами кодом** — отмечаешь нужные сайты и получаешь короткий код вроде `K7M-4QX`; друг вводит его в своём Zapret, и сайты появляются у него вместе с группами
- **Перетаскивание** — сайты и группы можно менять местами мышкой и переносить сайты между группами
- **Telegram** — один переключатель запускает [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) от Flowseal, кнопка «Подключить» сама настраивает Telegram Desktop и прячется, когда Telegram уже подключён
- **Telegram на телефоне** — QR-код: наводишь камеру, и телефон в той же Wi-Fi сети подключается к прокси на компьютере
- **Тест стратегий** прямо в окне — быстрые параллельные проверки, выбор групп сайтов и стратегий, рейтинг и кнопка «Включить» для лучшей
- **Внешний вид** — тёмная и светлая тема, выбор акцентного цвета, русский и английский язык
- **Трей** — сворачивается в трей, а правой кнопкой по значку можно включить или выключить zapret и Telegram или закрыть приложение
- **Запуск вместе с Windows** — по желанию, включается в настройках
- **Лёгкое и быстрое** — написано на C#, запускается мгновенно; проверки идут в фоне и редко, свёрнутое окно почти ничего не делает
- **Настройки**: игровой фильтр, IPSet, запуск без запроса прав администратора
- **Обновление zapret в один клик** — новая версия скачивается сама, сайты и настройки переезжают автоматически
- **Автообновление** приложения прямо в окне, без установщика; обновления сверяются по контрольной сумме
- **Удаление из настроек** — полностью или с сохранением zapret от Flowseal на рабочем столе
- **Безопасность** — папку Zapret могут менять только администраторы, поэтому другие программы не подменят файлы, которые запускаются с правами администратора

## Установка

1. Скачай `ZapretSetup.exe` из раздела [Releases](../../releases/latest).
2. Запусти и подтверди права администратора.
3. Установщик сам найдёт уже установленный zapret (вместе с твоими сайтами и настройками) или скачает свежий с GitHub автора.

Если у тебя стоит старая версия (на PowerShell), установщик сам обновит её и уберёт всё лишнее — сайты и настройки сохранятся.

По умолчанию всё ставится в `C:\Zapret`. Удалить можно в Zapret («Настройки → Инструменты → Удалить Zapret») или через «Параметры → Приложения».

> Windows Defender иногда ругается на `winws.exe` и драйвер WinDivert — это особенность самого zapret.
